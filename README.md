# The Wheel

## 🚀 How to get the wheel turnin'

> `npm install`  
> `cd ios && RCT_NEW_ARCH_ENABLED=1 pod install && cd ..`  
> `npx expo run:ios` or `npx expo run:android`  
> `npm start`  


> config changes require `npx expo prebuild` to update native directories


> cleanup command `npm cache clean --force && rm -rf node_modules package-lock.json ios/build ios/Podfile.lock ios/Pods && npm install && cd ios && RCT_NEW_ARCH_ENABLED=1 pod install && cd .. `
